# Community launch kit

This page keeps the public launch message factual and easy to reuse. It is
intended for the repository owner and contributors; it does not claim user,
download, revenue, or performance numbers that have not been published and
verified.

## Short announcement

NurAI is now open source. It is an Islamic companion app for worship,
learning, reflection, family, and gentle personal guidance, built with Expo,
React Native, TypeScript, Express, Drizzle, and PostgreSQL.

The community repository includes the app client, server, shared contracts,
migrations, design system, native iOS project, and contribution guidance. It is
a work in progress, and some services need your own local credentials. Help us
make the product more trustworthy, accessible, source-aware, and useful:

https://github.com/HamidA1998/NurAi-community

## Longer announcement

We are opening NurAI to developers, designers, researchers, translators, and
reviewers who want to help build a calm, trustworthy Islamic companion.

You can explore the mobile client, server routes, shared contracts, database
migrations, design tokens, and native iOS work. Contributions are welcome in
accessibility, testing, privacy, performance, documentation, offline support,
source and licensing review, Arabic learning, Quran study experiences, and
careful AI product design.

Please read the contribution, security, and content-license guidance first.
The community edition intentionally excludes production credentials, private
user data, release evidence, and media whose redistribution rights are not yet
clear.

Repository: https://github.com/HamidA1998/NurAi-community

## Launch checklist

- Keep the GitHub repository public and its README, license, security policy,
  code of conduct, and contribution guide current.
- Invite contributors through focused issues rather than vague requests for
  free work.
- Review every religious, medical, privacy, and third-party-media change with
  the appropriate subject-matter or rights review.
- Publish only claims that can be checked from the repository or an authoritative
  product surface.
- Thank contributors in release notes and review pull requests promptly.
